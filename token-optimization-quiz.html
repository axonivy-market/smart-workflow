Answer Key

Answers & explanations

Use the explanations to review the underlying principle.

1. B

Tokens are model text units. A token can correspond to a word, a word fragment, or punctuation; tokenization varies by model.

2. A

Unneeded context uses input capacity and can add cost. Include the information needed for the task, not everything available.

3. B

Tool definitions are part of what the model receives. Granting only relevant tools reduces overhead and narrows the choices it must consider.

4. C

A concise, specific description helps the model select the tool correctly without spending tokens on irrelevant implementation detail.

5. A

A focused summary can preserve the facts needed for the next step while avoiding repeated transmission of a large history.

6. B

Task-appropriate output limits and a clear format help prevent unnecessarily long responses while retaining enough room for a useful answer.

7. B

Usage and cost measurements reveal which calls dominate. Optimize based on observed data rather than prompt appearance alone.

8. A

Removing redundant wording preserves the instructions that affect correctness. Keep essential context, constraints, and output requirements.

9. B

Over-compression can discard necessary facts or precise constraints, lowering quality and potentially causing costly retries.

10. C

Measure first, make targeted reductions, and evaluate quality. A token reduction is only useful if the workflow still performs its task reliably.
